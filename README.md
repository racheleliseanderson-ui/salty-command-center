Upgrade Salty Desk into a high-end, clear command center and entry point for the Salty & Clever host-and-dine intelligence suite.

### Role of This Application

Salty Desk is the unified landing and orientation surface for three independent tools:

1. Menu Builder

2. Occasion Operating System

3. Restaurant Intelligence

It should help the user understand what each tool does, choose the right starting point, and move between them with clear, explicit handoffs — without embedding the tools themselves.

### Core Philosophy (do not break)

- Reader-job-first

- Explicit handoffs only (nothing moves between tools unless the user chooses)

- Educational planning only

- First-party evidence

- No allergen safety guarantees

- Vanity is allowed, but the kitchen still has to finish on time

- Fail-closed on hard constraints

### Intelligence & Clarity Upgrades

Make the desk significantly clearer and more useful as a decision surface:

- Sharpen the distinction between the three tools so a user immediately understands when to use Menu Builder vs Occasion Operating System vs Restaurant Intelligence

- Improve the Host Path guidance so it clearly sequences the recommended order (Menu Builder → Occasion Operating System, with Restaurant Intelligence as the dine-out alternative)

- Make the Handoff map clearer and more trustworthy — show exactly what moves between tools and what stays behind

- Surface the current live status of the three tools cleanly (without clutter)

- Strengthen the "Before you commit the kitchen" framing so it feels like a real decision moment

### Visual Design (High-End)

Elevate the current dark, atmospheric interface into a refined, high-end command desk:

- Aesthetic: Luxury editorial meets precise operational console. Deep refined tones, excellent typography hierarchy, strong visual hierarchy, purposeful spacing

- Hero and tool cards should feel premium and intentional, not generic

- Clear visual language that separates Host Path, individual tools, and Handoffs

- Beautiful, calm empty and loading states

- The overall feeling should be sharp, controlled, and high-trust

### Workflow Upgrades

Make the experience of entering the suite smoother and more purposeful:

- Create a clearer primary path for users who want to host at home

- Create a clear alternative path for users who want to dine out

- Make the handoff points between the three tools explicit, visible, and low-friction

- Keep the three applications independent — Salty Desk orients and routes; it does not absorb their functionality

### Tone & Voice

Keep the precise, slightly dry, intelligent voice. Avoid lifestyle fluff or soft marketing language. The desk should feel like a sharp operations surface that respects real constraints.

Start from the current live application as the baseline. Elevate clarity, visual quality, and routing intelligence so Salty Desk becomes a strong, high-end front door for the entire host-and-dine suite. Please complete full GitHub handoff new directory.
